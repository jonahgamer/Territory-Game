Tutorial

Logic is the optional grader on a problem. Leave it empty and the student's text is compared with the saved answer, ignoring capital letters and spaces around it. Paste one of the scripts below into Logic when the answer needs a custom check.

What the script can use

  • answer is the text the student submitted.
  • expected is the answer saved on the problem.
  • Set result.score from 0 to 100. A score of 100 accepts the answer and the team claims the cell.
  • Set result.comment to the message the student sees when the answer is not accepted.

You can also return true, false, a number, or { score, comment }. The cell still scores by difficulty: Easy 1, Normal 2, Hard 3, Insane 4. The script has math, JSON, strings, numbers, and arrays. It cannot read files or use the network, and it stops after one second. Students never see the script or the saved answer. A problem still needs both a question and an answer before it can be saved.

Exact text

const given = answer.trim().toLowerCase();
const want = expected.trim().toLowerCase();
if (given === want) {
  result.score = 100;
} else {
  result.score = 0;
  result.comment = "That answer is not right.";
}

Several accepted answers

Put one accepted answer on each line of the Answer field.

const given = answer.trim().toLowerCase();
const accepted = expected
  .split(/\r?\n/)
  .map((line) => line.trim().toLowerCase())
  .filter(Boolean);
if (accepted.includes(given)) {
  result.score = 100;
} else {
  result.score = 0;
  result.comment = "Try another form of the answer.";
}

A number, with a little room

Put the target in Answer, such as 3.14. This accepts anything within 0.01.

const given = Number(answer);
const want = Number(expected);
if (!Number.isFinite(given)) {
  result.score = 0;
  result.comment = "Enter a number.";
} else if (Math.abs(given - want) <= 0.01) {
  result.score = 100;
} else {
  result.score = 0;
  result.comment = "Not close enough.";
}

A list of values

Ask the student to separate values with |. Save the solution the same way, such as 8|1|6|3|5|7|4|9|2.

const given = answer.split("|").map((part) => part.trim());
const want = expected.split("|").map((part) => part.trim());
if (given.length === want.length && given.every((part, i) => part === want[i])) {
  result.score = 100;
} else {
  result.score = 0;
  result.comment = "Check the values and try again.";
}
