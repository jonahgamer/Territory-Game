    Tutorial

    Maps

    Create a map in Maps, then paint it. Each cell can hold a problem, a spawn point, an obstacle, or be left empty.

    • Problem cells are solved by students to claim territory.
    • Spawn points are where teams start.
    • Obstacles cannot be claimed.

    Problems

    Add problems from Problems. Each has a type, a difficulty, a prompt, an answer, and optional server-side logic.

    // Example logic: case-insensitive compare
const normalize = (s) => s.trim().toLowerCase();
if (normalize(answer) === normalize(expected)) {
  return { score: 100, comment: "AC" };
}
return { score: 0, comment: "WA" };

    Contests

    Create a contest in Contests, choose a map, set a schedule, then add teams. Each team has 1–5 students.

    During a contest

    • Spawn phase: every team member picks a spawn point; the team agrees when everyone picks the same cell.
    • Ready phase: spawn points are locked.
    • Live phase: click a problem next to your territory, solve it, and claim that cell.

    Easy problems are worth 1 point, normal 2, hard 3, and insane 4.
