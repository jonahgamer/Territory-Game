    Problems

    An index is the year and the problem number, such as 26000 for year 26, problem 000. The map shows the type tag in front, such as M26000. The same index can be used in another type. Choosing an index that already exists in this type swaps the two problems.

    Testing problems can be placed only on a testing map. A testing map can also use Math, OI, Science, and Puzzle. An official contest never includes Testing problems.

    Students see this difficulty as the cell color. On this map, difficulty is the colored border.

    Use $x^2$ for inline math and $$x^2$$ on its own line. HTML in the problem is shown in an isolated statement frame. Its scripts can run inside that frame and can update the answer through the answer bridge, but they cannot close the problem or change the rest of the page. The answer is the exact text a student types. Logic is optional JavaScript. It can read answer and expected, then set result.score from 0 to 100 and result.comment. A score of 100 is correct. Leave logic empty to compare the answer as text.
