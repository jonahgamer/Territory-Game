    Problems

    The map shows the type tag followed by this index, such as MO3. The same index can be used in another type. Choosing an index that already exists in this type swaps the two problems.

    Students see this difficulty as the cell color. On this map, difficulty is the colored border.

    Use $x^2$ for inline math and $$x^2$$ on its own line. HTML in the problem is shown in an isolated statement. Scripts, event handlers, stylesheets, and links are removed so they cannot change the answer box or close the problem. The answer is the exact text a student types. Logic is optional JavaScript. It can read answer and expected, then set result.score from 0 to 100 and result.comment. A score of 100 is correct. Leave logic empty to compare the answer as text.
